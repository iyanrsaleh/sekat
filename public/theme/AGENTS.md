# Panduan agen pengembang tema

Berkas ini untuk pengembang yang menyusun kulit situs memakai agen di luar dashboard, misalnya Cursor, Claude, atau OpenCode. Baca juga `README.md` di folder yang sama.

## Wilayah kerja

- Ubah hanya HTML dan CSS di folder ini.
- Jangan menulis PHP.
- Jangan memindahkan atau mengubah `public/assets/js/`.
- Jangan menyentuh `public/dashboard/`.
- CSS tema ada di `theme/assets/css/`. Jangan mengarah ke `assets/css/` untuk gaya kulit.
