# Web publik

Gaya tidak diikat. `assets/css/style.css` hanya contoh minimal: halaman sempit, form, dan pesan kesalahan.

Proyek umum mengganti berkas itu, atau menambah berkas CSS sendiri. Mesin di `vendor/` tidak membaca nama class dan tidak menyusun tampilan.

Yang dipakai halaman contoh: path relatif (`assets/css/style.css`, `assets/js/app.js`) dan `fetch()` ke API (`api/ping`, `api/posts`). Kepala halaman ada di `header.html`, kaki di `footer.html`.
