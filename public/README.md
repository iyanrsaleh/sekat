# Web publik

Kulit situs ada di `theme/`. Folder aplikasi (`dashboard/`) tetap di sini.

Gaya tidak diikat. `theme/assets/css/style.css` hanya contoh minimal. Skrip pengikat API tetap di `assets/js/`.

Yang dipakai halaman contoh: path relatif (`theme/assets/css/style.css`, `assets/js/app.js`) dan `fetch()` ke API (`api/ping`, `api/posts`). Kepala halaman ada di `theme/header.html`, kaki di `theme/footer.html`.
